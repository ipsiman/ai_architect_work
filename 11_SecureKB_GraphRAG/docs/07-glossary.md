# Словарь терминов и сокращений

Термины отсортированы по латинскому алфавиту (без учёта регистра, цифры перед буквами). Формат: сокращение | расшифровка (англ.) | перевод/пояснение по-русски.

| Сокращение | Расшифровка (англ.) | Перевод / пояснение |
|---|---|---|
| ablation | ablation study | Абляция: контрольное отключение компонента (например, графа) для замера его вклада |
| ACL | Access Control List | Список контроля доступа; в SecureKB — метка уровня доступа чанка (public/internal/secret) |
| ADR | Architecture Decision Record | Запись об архитектурном решении: контекст, варианты, выбор и последствия |
| API | Application Programming Interface | Программный интерфейс взаимодействия компонентов |
| AWQ | Activation-aware Weight Quantization | Квантование весов с учётом активаций; формат компактных моделей для GPU-инференса (vLLM) |
| BM25 | Best Match 25 | Классический лексический алгоритм ранжирования по вхождениям терминов |
| C4 | Context, Containers, Components, Code | Модель архитектурных диаграмм четырёх уровней детализации |
| CAPEX/OPEX | Capital / Operational Expenditure | Капитальные (разовые) и операционные (текущие) затраты |
| chunk | chunk | Чанк — фрагмент документа, единица индексации и контроля доступа |
| CI | Continuous Integration | Непрерывная интеграция: автосборка и автотесты при каждом коммите |
| Control/Data Plane | Control / Data Plane | Плоскость управления (конфигурация, политики) и плоскость данных (трафик запросов) |
| defense-in-depth | defense in depth | Эшелонированная оборона: несколько независимых контуров защиты на пути запроса |
| DFD | Data Flow Diagram | Диаграмма потоков данных |
| DMZ | Demilitarized Zone | Демилитаризованная зона: буферный сетевой сегмент между внешней сетью и ядром |
| embedding | embedding | Эмбеддинг — векторное представление текста для плотного поиска |
| ER | Entity-Relationship | Модель «сущность-связь» для описания структуры данных |
| FTE | Full-Time Equivalent | Эквивалент полной занятости; доля FTE — мера трудозатрат |
| GGUF | GPT-Generated Unified Format | Формат файлов квантованных моделей для llama.cpp |
| golden Q/A | golden questions/answers | Эталонный набор пар «вопрос — ответ» для регрессионной проверки качества RAG |
| GraphRAG | Graph-based Retrieval-Augmented Generation | RAG с графом знаний: расширение выдачи связями между сущностями |
| guardrail | guardrail | Ограничитель: фильтр запроса или ответа (инъекции, PII, запрещённый контент) |
| HA | High Availability | Высокая доступность: отказ узла не останавливает сервис |
| JWT | JSON Web Token | Подписанный токен, удостоверяющий пользователя; выдаётся SSO в целевой архитектуре |
| K8s | Kubernetes | Оркестратор контейнеров для эксплуатации в масштабе |
| LDAP | Lightweight Directory Access Protocol | Протокол корпоративного каталога пользователей и ролей |
| LLM | Large Language Model | Большая языковая модель |
| MPS/Metal | Metal Performance Shaders / Metal | API GPU Apple Silicon, через которое выполняется инференс в MVP |
| MVP | Minimum Viable Product | Минимально жизнеспособный продукт: проверка гипотез минимальными средствами |
| Neo4j | Neo4j | Графовая СУБД целевой архитектуры (фаза 2) |
| OTel | OpenTelemetry | Открытый стандарт трейсинга, метрик и логов |
| p50/p95/p99 | 50th/95th/99th percentile | Перцентили распределения: медиана и «хвосты» латентности |
| PII | Personally Identifiable Information | Персональные данные; в конвейере маскируются на ingestion и на входе запроса |
| pre-filter/post-filter | pre / post filtering | Фильтрация доступа до retrieval (в Query-фильтре Qdrant) либо после выдачи |
| prompt injection | prompt injection | Инъекция в промпт: попытка переопределить инструкции модели через текст запроса |
| Qdrant | Qdrant | Векторная БД open-source, хранилище эмбеддингов с payload-фильтрами |
| RAG | Retrieval-Augmented Generation | Генерация с дополнением из поиска: ответ модели опирается на найденные документы |
| RBAC | Role-Based Access Control | Доступ по ролям; в проекте уровни ACL пользователя фильтруют выдачу |
| red-team | red teaming | Атакующее тестирование защиты «своими силами» до выхода в прод |
| RPS | Requests Per Second | Запросов в секунду — пропускная способность сервиса |
| RRF | Reciprocal Rank Fusion | Обратное ранговое слияние: объединение нескольких выдач (векторы, BM25, граф) |
| SLA | Service Level Agreement | Соглашение об уровне сервиса: целевые значения доступности и латентности |
| SQLite | SQLite | Встраиваемая реляционная СУБД; в MVP хранит граф, пользователей, аудит |
| SSE | Server-Sent Events | Потоковая передача событий сервером; транспорт токенов ответа |
| SSO | Single Sign-On | Единая точка входа; в целевой архитектуре через LDAP/JWT |
| TCO | Total Cost of Ownership | Совокупная стоимость владения: инфраструктура, персонал, сопровождение |
| TTFT | Time To First Token | Время до первого токена ответа; метрика отзывчивости стриминга |
| Vault | HashiCorp Vault | Хранилище секретов с ротацией и аудитом доступа (целевая архитектура) |
| vLLM | vLLM | GPU-движок инференса LLM: continuous batching, PagedAttention |
| VLM | Vision Language Model | Мультимодальная модель «изображение+текст» (Qwen-VL в целевой архитектуре) |
| WAF | Web Application Firewall | Межсетевой экран уровня приложения: фильтрация атак на API |
