# Реестр архитектурных решений (ADR)

Документы фиксируют ключевые проектные решения SecureKB: контекст, рассмотренные
альтернативы, принятое решение и последствия. Формат — легковесный ADR (Architecture
Decision Record, запись об архитектурном решении). Изменение
решения оформляется новым ADR со статусом «Отменено» у прежнего.
